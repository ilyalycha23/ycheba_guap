# Web-технологии

Клиентская веб-разработка: вёрстка, JavaScript и курсовой проект.

## Содержимое

| Папка | Описание |
|-------|----------|
| `web-технологии (лабы)/` | Лабораторные 1–9 + PDF-отчёты |
| `kyrsach (main)/` | Курсовая работа (сайт) |

## Лабораторные

Папки `1` … `9` — отдельные работы. Рядом лежат отчёты `WEB_ЛР*_ЛАВ.pdf`.

**Стек лаб:** HTML, CSS, JavaScript.

## Курсовая

Статический сайт с макетом (Figma), разметкой и скриптами. Подробности — в `kyrsach (main)/README.md`.

```
kyrsach (main)/
├── index.html
├── style.css
├── script.js
├── data/          # данные страниц
├── images/
├── react/         # доп. часть
└── отчеты/
```
