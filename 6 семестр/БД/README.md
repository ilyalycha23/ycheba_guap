# Базы данных

Лабораторные по аналитике данных в **Loginom** и материалы к экзамену.

## Содержимое

| Папка | Описание |
|-------|----------|
| `лр1` … `лр9` | Лабораторные работы (сценарии `.lgp`, данные, отчёты) |
| `БД_экз/` | Билеты и краткий конспект к экзамену |

## Формат работ

Типичная структура лабы:

```
лрN/
├── *.lgp          # сценарий Loginom
├── Данные/        # исходные наборы
├── Результаты/    # выгрузки (если есть)
└── БД_ЛР*.docx    # отчёт
```

## Экзамен

В `БД_экз/` — билеты и сжатый конспект в `.docx` / `.pdf`.
