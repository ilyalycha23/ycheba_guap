# Интернет вещей

Лабораторные по IoT: веб-интерфейсы «вещей», бэкенд на Flask и хранение в MongoDB.

## Содержимое

| Элемент | Описание |
|---------|----------|
| `1ая лаба` … `9ая лаба` | Девять лабораторных работ |
| `Методическое пособие ИВ.pdf` | Методичка по курсу |

## Стек

- **Python** + **Flask**
- **MongoDB** (`pymongo`)
- HTML-шаблоны (`templates/`) и статика (`static/`)

Зависимости (пример из поздних лаб):

```
flask>=3.0.0
pymongo>=4.6.0
```

## Типичная структура лабы

```
Nая лаба/
├── app.py / things.py
├── templates/
├── static/
├── requirements.txt   # где есть
└── ЛР*_ИВ*.pdf        # отчёт
```
