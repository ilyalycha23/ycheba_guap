# КИСП

Корпоративные информационные системы на платформе **1С:Предприятие**.

## Содержимое

| Элемент | Описание |
|---------|----------|
| `ЛР*_ЛаврешинКИСП.docx/.pdf` | Отчёты по лабораторным |
| `*.dt` | Выгрузки информационных баз |
| `Курсовая/` | Курсовой проект (киноцентр / 1С) |

## Курсовая

В `Курсовая/` — конфигурация 1С, исходники (`Greg/`, `ДляГита/`), логи и материалы отчёта.

Основные артефакты:

- `1Cv8.1CD` — файл ИБ
- `Greg/` — исходники конфигурации и документация
- `ДляГита/` — версия для публикации
