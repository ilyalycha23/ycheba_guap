# Курсовая работа: Продажа билетов в киноцентре (1С:Предприятие 8.3/8.5)

Конфигурация 1С для управления киноцентром: продажа и бронирование билетов, учёт кинозалов, бар, финансовые отчёты и бизнес-процессы обслуживания посетителей.

## Структура репозитория

- `src/` — исходные XML-файлы конфигурации (выгрузка).
- `../img/` — исходные PNG-иконки разделов меню (подключены в конфигурации как `CommonPicture.Icon*`).
- `tools/refactor-metadata.py` — скрипт полного переименования метаданных.
- `tools/cc-1c-skills/` — навыки для работы с конфигурацией через CLI.

## Объекты метаданных (внутренние имена)

| Область | Объекты |
|---------|---------|
| НСИ | `Кинозалы`, `ТипыБилетов`, `Фильмы`, `Клиенты`, `Сотрудники`, `Номенклатура` |
| Документы | `ЗаявкаНаБроньБилетов`, `ПродажаБилетов`, `Оплата`, `ЗаказВБар`, документы бара |
| Регистры | `ВыручкаПоБилетам` (ресурс `КоличествоБилетов`), `ИсторияСтатусовЗалов`, `ОстаткиТоваров` |
| Перечисления | `СтатусыЗалов`, `СостоянияЗалов` |
| Бизнес-процесс | `ОбслуживаниеПосетителя` (точки: `ВстречаПосетителя` → `ПросмотрФильма` → `ОплатаБилетов`) |
| Отчёты | `ЗаполняемостьЗалов`, `Финансы`, `Бюджет` |
| Подсистемы | `ПродажаБилетов`, `БарКинотеатра`, `НСИ`, `Финансы`, `Отчетность`, `Задачи` |

## Бизнес-логика

1. **Заявка на бронь билетов** — клиент, фильм, кинозал, тип билета, количество → запуск БП.
2. **Продажа билетов** — проведение билетов, движения по `ВыручкаПоБилетам` и `ИсторияСтатусовЗалов`.
3. **Заказ в бар** — независимый процесс во время сеанса.
4. VIP-билет доступен только для VIP-зала; закрытый зал нельзя забронировать.

## Регистры накопления в меню

Команды регистров в 1С по умолчанию **скрыты** — включены в командном интерфейсе подсистем.

| Регистр | Где в меню |
|---------|------------|
| **Выручка по билетам** | **Финансы** и **Продажа билетов** → «См. также» → «Выручка по билетам» |
| **Остатки товаров** | **Финансы** и **Бар кинотеатра** → «См. также» → «Остатки товаров» |

Роль **Оператор** имеет права Read/View на оба регистра.

## Демо-данные

Тестовые данные **уже включены в информационную базу** — файл **`Greg\КурсоваяИТОГ.dt`**. Для сдачи курсовой достаточно развернуть этот дамп в 1С.

### Что в базе

| Раздел | Содержимое |
|--------|------------|
| Фильмы | 6 фильмов (Матрица, Брат, Аватар и др.) |
| Кинозалы | 4 зала (Standard + VIP) |
| Типы билетов | Стандарт, Льготный, VIP, Абонемент |
| Клиенты | 5 клиентов с телефонами |
| Сотрудники | 4 сотрудника + адресация задач |
| Номенклатура | 6 позиций бара |
| Документы | Операции за **прошлый календарный месяц** (заявки, продажи, оплаты, бар, товары, БП и задачи) |

### Развёртывание

1. В конфигураторе: **Администрирование → Загрузить информационную базу** → выбрать `Greg\КурсоваяИТОГ.dt`.
2. Либо загрузить конфигурацию из `src/` в существующую базу, если дамп уже развёрнут.

В отчётах **Финансы**, **Бюджет**, **Заполняемость залов** по умолчанию период **«Прошлый месяц»**.

Обработка автозаполнения из конфигурации **удалена** — данные хранятся в `.dt`, повторное заполнение из интерфейса не требуется.

## «Объект не найден» в колонке «Должность» (задачи)

После очистки дубликатов должностей в задачах могут остаться **битые ссылки** на удалённые элементы справочника. Это исправляется автоматически.

### Что сделать

1. **Закройте все окна 1С** (и конфигуратор, и предприятие).
2. Загрузите актуальную конфигурацию из `Greg\src` (команда выше).
3. **Запустите 1С:Предприятие** под пользователем «Администратор».

Если снова «недостаточно прав»: в конфигураторе **Администрирование → Пользователи → Администратор → Роли** — включите **Полные права** и **Оператор**, затем перезапустите предприятие.

4. При входе задачи исправляются автоматически (модуль сеанса).
5. Проверьте список **Задача исполнителя**: «Должность» — «Администратор», «Сотрудник» — «Смирнова Елена Викторовна».

Лог исправления (если нужен): `D:\ycheba_guap\КИСП\Курсовая\kinocenter-fix-log.txt`

После исправления можно обновить дамп для сдачи:
