# Продажа билетов в киноцентре

Учебная конфигурация **1С:Предприятие 8.5** для автоматизации деятельности киноцентра.  
Разработана в рамках курсовой работы.

> **Важно:** это **учебное прикладное решение**, а не коммерческий продукт.  
> Используется **учебная версия платформы** (`1cv8t`). Конфигурация предназначена для демонстрации, отработки типовых объектов метаданных и изучения встроенного языка 1С.

---

## О предприятии

**Киноцентр** — организация, которая одновременно:

- продаёт билеты на киносеансы;
- ведёт учёт зрительных залов и их занятости;
- обслуживает посетителей в баре (попкорн, напитки и т.п.);
- фиксирует оплату и формирует упрощённую финансовую отчётность.

Типовой сценарий работы:

1. Кассир оформляет **заявку на бронь билетов** (фильм, зал, тип билета, время сеанса).
2. Система запускает **бизнес-процесс обслуживания посетителя**.
3. Оформляется **продажа билетов**, фиксируется выручка и статус зала.
4. Во время сеанса посетитель может сделать **заказ в бар** — задача уходит администратору зала.
5. По завершении визита оформляется **оплата**, бизнес-процесс закрывается.
6. Параллельно ведётся **складской учёт бара** (поступление, продажа, списание товаров).
7. Руководство анализирует результаты через **отчёты**.

## Возможности системы

### Продажа билетов

- Справочники: **клиенты**, **фильмы**, **кинозалы**, **типы билетов**.
- Документы: **заявка на бронь билетов**, **продажа билетов**, **заказ в бар**, **оплата**.
- Автоматический расчёт суммы и времени окончания сеанса по длительности фильма.
- Проверки при проведении:
  - VIP-билет только для VIP-зала;
  - нельзя бронировать в закрытый (списанный) зал;
  - количество билетов больше нуля;
  - окончание сеанса не раньше начала.
- Команда **«Завершить сеанс»** на форме продажи: оплата и закрытие этапов без ручного перехода между документами.
- Регистр накопления **«Выручка по билетам»** (клиент, зал, тип билета, сумма, количество).

### Бар кинотеатра

- Справочник **номенклатура** (товары бара).
- Документы: **поступление товаров**, **продажа товаров**, **списание товаров**.
- Регистр накопления **«Остатки товаров»**.
- Контроль остатков перед продажей и списанием.
- **Заказ в бар**: при проведении создаётся задача администратору; процедура **«ЗавершитьЗаказ»** автоматически оформляет продажу товара и оплату.

### Задачи и бизнес-процесс

- Бизнес-процесс **«Обслуживание посетителя»** с этапами:
  - **Встреча посетителя** (кассир);
  - **Просмотр фильма** (администратор зала);
  - **Оплата билетов** (управляющий).
- Задача **«Задача исполнителя»** с адресацией по должностям.
- Регистры сведений: **«Адресация задач»**, **«История статусов залов»**.

### Финансы

- Документ **«Оплата»**.
- План счетов **«План счетов»** (счета 50 «Касса», 62 «Взаиморасчёты с клиентами», 90 «Выручка»).
- План видов характеристик **«Виды субконто»** (аналитика по клиентам).
- Регистр бухгалтерии **«Проводки»**.
- Отчёт **«Бюджет»** — свод по статьям: стартовый капитал, маржа по билетам, продажи в баре, закуп товаров.

### Отчётность

| Отчёт | Назначение |
|-------|------------|
| **Заполняемость залов** | Количество билетов и выручка по залам и типам билетов за период |
| **Финансы** | Финансовый результат по клиентам: факт vs начисление, себестоимость залов, сверхприбыль, чистая прибыль |
| **Бюджет** | Сводное денежное состояние киноцентра |

**Справочники:** `Кинозалы`, `ТипыБилетов`, `Фильмы`, `Клиенты`, `Должности`, `Сотрудники`, `Номенклатура`.

**Документы:** `ЗаявкаНаБроньБилетов`, `ПродажаБилетов`, `Оплата`, `ЗаказВБар`, `ПоступлениеТоваров`, `ПродажаТоваров`, `СписаниеТоваров`.

**Регистры накопления:** `ВыручкаПоБилетам`, `ОстаткиТоваров`.

**Регистры сведений:** `ИсторияСтатусовЗалов`, `АдресацияЗадач`.

**Прочее:** бизнес-процесс `ОбслуживаниеПосетителя`, задача `ЗадачаИсполнителя`, план счетов `Управленческий` (синоним «План счетов»), регистр бухгалтерии `Проводки`.

**Перечисления:** `СтатусыЗалов` (свободен, занят, забронирован, закрыт), `СостоянияЗалов` (работает, списан).

## Прикладная логика (основные алгоритмы)

Реализована на встроенном языке в модулях объектов и форм:

- расчёт суммы заявки по категории билета (за билет / пакет / абонемент);
- автоматическое время окончания сеанса по продолжительности фильма;
- проверки VIP-зала, закрытого зала, количества и времени сеанса;
- запуск бизнес-процесса при проведении заявки;
- движения по выручке, истории статусов залов и проводкам при продаже;
- создание задачи при заказе в бар;
- проверка остатков товаров запросом к регистру;
- автоматическое завершение заказа в баре (продажа + оплата).

## Ограничения учебной версии

- Конфигурация **не предназначена** для эксплуатации в реальном киноцентре.
- Учебная платформа **1cv8t** имеет ограничения по сравнению с промышленной поставкой 1С.
- Упрощённый план счетов и учёт — для демонстрации методики курсовой, а не для сдачи бухгалтерской отчётности.
- Часть сценариев (например, онлайн-бронирование, интеграция с кассой ККТ) **намеренно не реализована**.
