# Методы и средства проектирования

Проектирование схем БД и работа с **SQL / PostgreSQL**.

## Содержимое

| Элемент | Описание |
|---------|----------|
| `lab1` … `lab8` | Восемь лабораторных |
| `методичка.pdf` | Методические указания |

## Что в лабах

- SQL-скрипты (`*.sql`) — схемы, ограничения, каскады, тестовые данные
- Диаграммы ER (`*.pgerd` и др.)
- Отчёты `ЛР*_МИСП_Лаврешин.docx/.pdf`

Пример (`lab1`):

```
lab1/
├── 01_schema.sql
├── er-diagramm.pgerd
└── ЛР1_МИСП_Лаврешин.pdf
```
