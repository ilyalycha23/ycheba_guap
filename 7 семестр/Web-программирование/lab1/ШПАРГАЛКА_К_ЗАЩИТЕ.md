## 30 секунд про проект
**SignalBoard** — доска локальных сигналов для соседей одного дома/двора.  
Проблема: объявления «ищу / отдаю / предупреждаю» тонут в чатах.  
Сущность: **сигнал**. Функции: лента, фильтры по типу, кабинет. Тема на все 7 лаб.

## Частые вопросы — короткие ответы

| Вопрос | Ответ в одно предложение |
|--------|---------------------------|
| Что такое компонент? | Функция с большой буквы, возвращает JSX. |
| Что такое props? | Входные данные компонента, только чтение. |
| Зачем TypeScript? | Типы ловят ошибки до запуска. |
| Что такое App Router? | Маршруты из папок в `app`. |
| `page.tsx`? | Страница URL. |
| `layout.tsx`? | Общая оболочка + `children`. |
| Server vs Client? | По умолчанию server; client — для кликов/state (`"use client"`). |
| Зачем Link? | Навигация Next без полной перезагрузки. |
| Почему нет Tailwind/src? | Так требует методичка курса. |
| Почему нет БД? | ЛР1 — только каркас. |

## Если спросят «чем не TheraCity?»
У TheraCity сущности — фото, маршруты, пользователи.  
У нас — **сигналы соседей** (тип объявления, лента, фильтры). Логика курса та же (несколько разделов → к 7-й лабе полноценное приложение), тема другая.
