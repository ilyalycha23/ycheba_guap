# Лабораторная работа № 2 — что сделано и почему

**Тема проекта:** SignalBoard — доска локальных сигналов соседям  
**Папка проекта:** `signalboard/`  
**Методичка:** создание структуры App Router и учебного прототипа авторизации

Это продолжение ЛР1: те же проблема, аудитория и сущность (**сигнал**). Новый проект не создавался — каркас из двух страниц превращён в многостраничное приложение.

---

## Что реализовано

| Назначение | Каталог `app` | URL |
|---|---|---|
| Редирект на старт | `page.tsx` | `/` → `/start` |
| Стартовая страница | `start/page.tsx` | `/start` |
| Лента сигналов | `signals/page.tsx` | `/signals` |
| Карточка сигнала | `signals/[id]/page.tsx` | `/signals/{id}` |
| О проекте | `about/page.tsx` | `/about` |
| Личный кабинет | `cabinet/page.tsx` | `/cabinet` |
| Вход | `auth/login/page.tsx` | `/auth/login` |
| Регистрация | `auth/register/page.tsx` | `/auth/register` |

Данные — массив `neighborSignals` в `app/data/signals.ts` (это **не** база данных). У каждого объекта есть `id`, `title`, `summary` и предметное поле `category` (`ищу` / `отдаю` / `предупреждаю`).

Неизвестный id, например `/signals/unknown`, вызывает `notFound()`.

---

## Как устроен учебный вход

`DemoAuthProvider` хранит `User | null` в `useState`.  
`login` берёт имя из email, `register` — из поля имени, `logout` обнуляет пользователя. Пароль **не сохраняется**.

Это прототип интерфейса:

- нет проверки пароля на сервере;
- нет cookie-сессии;
- после обновления страницы пользователь исчезает;
- скрытие кнопки «Выйти» не защищает данные.

Предупреждение о демонстрационном режиме на формах оставлять нельзя убирать до ЛР6.

---

## Server vs Client

- `/start`, `/signals`, `/signals/[id]`, `/about` — Server Components.  
- `AppNav`, `DemoAuthProvider`, формы и кабинет — `"use client"`, потому что нужны `useState`, `usePathname` и обработчики событий.

Навигация общая: `AppNav` подключён в корневом `layout.tsx`, активный пункт отмечается через `usePathname` и `aria-current="page"`.

---

## Как запустить

```bash
cd signalboard
npm install
npm run dev
```

Проверить:

1. `/start` → лента → две карточки → `/signals/unknown` даёт 404.  
2. Кабинет без входа предлагает форму.  
3. Короткий пароль показывает ошибку.  
4. Учебный вход показывает имя в шапке и кабинете.  
5. «Выйти» и обновление страницы сбрасывают состояние.

Затем: `npm run lint` и `npm run build`.
