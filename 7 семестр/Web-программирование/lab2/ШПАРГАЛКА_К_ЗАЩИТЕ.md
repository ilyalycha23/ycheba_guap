# Шпаргалка к защите ЛР2 — SignalBoard

Говори коротко. Если просят «покажи» — `cd signalboard`, `npm run dev`, кликай ленту, карточку, вход, кабинет, F5.

---

## 30 секунд про работу
Продолжение ЛР1: две страницы стали многостраничным приложением.  
Сущность — **сигнал**. Маршруты: `/start`, `/signals`, `/signals/[id]`, `/cabinet`, `/auth/login`, `/auth/register`.  
`DemoAuthProvider` — учебный вход в памяти вкладки. Это **не** безопасность.

## Частые вопросы — короткие ответы

| Вопрос | Ответ в одно предложение |
|--------|---------------------------|
| Как app становится URL? | Папка = сегмент, `page.tsx` = страница. |
| page vs layout? | Страница vs общая оболочка с `children`. |
| Зачем `[id]`? | Динамический сегмент адреса. |
| Зачем `await params`? | В актуальном App Router params — Promise. |
| Когда `"use client"`? | Хуки и клики: state, pathname, onClick. |
| Зачем Link? | Переход без полной перезагрузки, layout живёт. |
| Аутентификация? | Кто это. |
| Авторизация? | Имеет ли право. |
| Сессия? | Помнить вход между запросами. |
| Почему F5 сбрасывает вход? | `useState`, нет cookie. |
| Почему скрытая кнопка не защита? | Запрос можно отправить мимо UI. |
| Что заменит PostgreSQL/Prisma? | Массив, пароль, сессию и права на сервере. |
