# Лабораторная работа № 3 — что сделано и почему

**Тема:** SignalBoard  
**Папка проекта:** `signalboard/`  
**Методичка:** фотографии, модальные окна, бургер-меню, учебное состояние пользователя и карта

Продолжается ЛР2. Маршруты App Router и `DemoAuthProvider` сохранены. Добавлена клиентская интерактивность.

---

## Что добавлено

1. **Фото и координаты** у сигнала: `image`, `imageAlt`, `latitude`, `longitude`, `location`.  
   Файлы лежат в `public/images/places/` (учебные иллюстрации к трём сигналам двора).

2. **Галерея** `/gallery`:
   - `page.tsx` остаётся Server Component;
   - `SignalsGallery` — Client Component: хранит выбранный сигнал и обработчики.

3. **Модальное окно** через `createPortal(..., document.body)`:
   - `role="dialog"`, `aria-modal="true"`, `aria-labelledby`;
   - закрытие Escape и кликом только по фону;
   - фокус на кнопке закрытия, цикл Tab / Shift+Tab;
   - возврат фокуса на карточку;
   - блокировка прокрутки документа и cleanup в `useEffect`.

4. **Отслеживание сигнала** — учебный `Set` id в `useState`.  
   Вошедший пользователь видит кнопку «Отслеживать сигнал», гость — ссылку на вход.  
   После обновления страницы и пользователь, и отслеживание сбрасываются. Это не серверная авторизация.

5. **Бургер-меню** заменяет `AppNav` в `layout.tsx`:
   - `aria-expanded`, `aria-controls`;
   - закрытие по ссылке, Escape и фону;
   - возврат фокуса на кнопку открытия.

6. **Яндекс Карта**: скрипт API, `ymaps.ready`, `Map`, `Placemark`, клик по метке открывает то же модальное окно.  
   Карта уничтожается в cleanup. Без ключа показывается понятное сообщение.

---

## Ключ карты

Файл `.env.local` (не публиковать настоящий ключ):

```env
NEXT_PUBLIC_YANDEX_MAPS_API_KEY=ваш_ключ
```

Переменная с префиксом `NEXT_PUBLIC_` попадает в клиентский JavaScript, поэтому это не серверный секрет. После изменения файла перезапустите `npm run dev`.

---

## Как запустить

```bash
cd signalboard
npm install
npm run dev
```

Проверить: фото без 404, модалка с клавиатуры, меню, гость/пользователь, метки на карте (если ключ задан), сброс состояния после reload. Затем `npm run lint` и `npm run build`.
