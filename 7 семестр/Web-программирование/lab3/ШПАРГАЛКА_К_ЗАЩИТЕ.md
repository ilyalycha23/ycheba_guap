# Шпаргалка к защите ЛР3 — SignalBoard

Говори коротко. Если просят «покажи» — `cd signalboard`, `npm run dev`, открой `/gallery`: карточка → окно → Tab/Escape → меню → вход → «Отслеживать сигнал» → F5.

---

## 30 секунд про работу
Продолжение ЛР2. У сигнала появились фото и координаты.  
`/gallery`: карточки (`next/image`), модальное окно (`createPortal`), карта Яндекса с метками.  
Навигация — бургер-меню. Отслеживание — учебный `Set` в `useState`, это **не** авторизация.

## Частые вопросы — короткие ответы

| Вопрос | Ответ в одно предложение |
|--------|---------------------------|
| Зачем `"use client"`? | Граница клиентского модуля: state, эффекты, клики. |
| Почему page галереи серверная? | Она только подключает клиентский компонент. |
| Что возвращает useState? | `[значение, setЗначение]`. |
| Зачем useRef? | Ссылки на DOM и значения без ре-рендера. |
| Когда cleanup useEffect? | Перед повтором эффекта и при размонтировании. |
| Что делает портал? | Рендерит в `document.body`, но остаётся в дереве React. |
| Почему контекст виден в портале? | Дерево React не меняется, меняется только DOM. |
| Атрибуты диалога? | `role="dialog"`, `aria-modal="true"`, `aria-labelledby`. |
| Tab / Escape? | Tab по кругу внутри окна, Escape закрывает, фокус назад. |
| Почему button, а не div? | Фокус, Enter/пробел и роль из коробки. |
| Что даёт next/image? | srcset, ленивую загрузку, резерв места. |
| Где картинки? | `public/images/places`. |
| Зачем ymaps.ready? | Создавать карту только после готовности API. |
| Почему ключ карты не секрет? | `NEXT_PUBLIC_` попадает в браузерный бандл. |
| Почему скрытая кнопка не защита? | Проверка прав возможна только на сервере (ЛР6). |
