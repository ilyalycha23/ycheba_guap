# Лабораторная работа № 4 — что сделано и почему

**Тема:** SignalBoard  
**Папка проекта:** `signalboard/`  
**Методичка:** адаптивность клиентской части и контроль качества Lighthouse

Продолжается ЛР3. Маршруты, галерея, модальное окно, меню и карта сохранены. Задача — устойчивый макет на разных ширинах и проверка качества страницы.

---

## Что изменено

- В `layout.tsx` экспортирован `viewport` только для `themeColor` и `colorScheme`.  
  `width=device-width, initial-scale=1` Next.js добавляет сам. Масштабирование пользователя не отключалось.

- `globals.css`: токены, `min()` для ширины `main`, `clamp()` для отступов и заголовков, `prefers-reduced-motion`.  
  `overflow-x: hidden` не используется — он маскирует ошибку раскладки.

- Галерея: mobile-first сетка  
  `repeat(auto-fit, minmax(min(100%, 15rem), 1fr))`.  
  У `Image` с `fill` задан `sizes` под фактическую ширину карточки. Контейнер с `aspect-ratio: 3 / 2`.

- Hover карточки только при `(hover: hover) and (pointer: fine)`.

- Модальное окно: `width: min(...)`, `max-height` от `100dvh`, прокрутка содержимого, клавиатурная модель ЛР3 сохранена.

- Меню: на узком экране панель на всю ширину, высота `100dvh`, учёт `safe-area`.

- Карта: высота через `clamp()`, `ResizeObserver` вызывает `map.container.fitToViewport()`, observer отключается в cleanup.

## Ручная матрица ширин

Проверяйте `/gallery` на 320, 375, 768, 1024 и 1440 CSS px и при масштабе 200%: нет горизонтальной прокрутки, читаемый текст, доступны кнопки, работают меню, модалка и карта, виден `:focus-visible`.

## Lighthouse

Методичка требует три запуска **до** правок и три **после** на production:

```bash
npm run lint
npm run build
npm run start
```

В Chrome DevTools → Lighthouse: Mode Navigation, Device Mobile, категории Performance / Accessibility / Best Practices / SEO, Clear Storage включён. В отчёт идут медианы и сравнение LCP, TBT, CLS. Фиксированного проходного балла нет.

Исправления, уже заложенные в код под типичные аудиты:

1. осмысленные `sizes` и зарезервированный `aspect-ratio` (LCP / CLS);  
2. контраст и видимый `:focus-visible`;  
3. `title` / `description` через Metadata API.

Сами цифры Lighthouse нужно снять на своём компьютере — чужие результаты сдавать нельзя.

## Как запустить

```bash
cd signalboard

```
