# Шпаргалка к защите ЛР4 — SignalBoard

Если просят «покажи» — `npm run build && npm run start`, DevTools → Toggle device toolbar → 320 / 375 / 768 / 1024 / 1440, затем Ctrl+колесо до 200 %. Lighthouse — вкладка Lighthouse, Mobile, Navigation.

---

## 30 секунд про работу
Продолжение ЛР3, сделал интерфейс адаптивным (mobile-first).  
Сетка `auto-fit + minmax(min(100%,15rem),1fr)`, размеры через `clamp()`, окно и меню в `100dvh`, карта через `ResizeObserver → fitToViewport()`.  
Lighthouse: по 3 запуска до/после, исправил 3 аудита, Accessibility 95 → 100.

## Три исправления по Lighthouse
| Аудит | Причина | Исправление |
|-------|---------|-------------|
| aria-prohibited-attr | `aria-label` на div карты без роли | `role="region"` |
| lcp-lazy-loaded | LCP-картинка грузилась лениво | `loading="eager"` у первой карточки |
| lcp-discovery (fetchpriority) | нет высокого приоритета | `fetchPriority="high"` у первой карточки |

Медианы: Performance 99 → 99, Accessibility 95 → 100, BP 100, SEO 100, CLS 0.  
Render-blocking / unused JS / legacy JS — чанки самого Next.js, не трогал (объяснено в отчёте).

## Частые вопросы — короткие ответы

| Вопрос | Ответ |
|--------|-------|
| Responsive design? | Одна страница удобна на любых экранах. |
| Viewport по умолчанию? | `width=device-width, initial-scale=1`. |
| Mobile-first? | База для узкого, `min-width` добавляет. |
| Breakpoint по чему? | По месту, где ломается контент. |
| Grid vs Flex? | Двумерная vs одномерная раскладка. |
| auto-fit + minmax? | Сколько влезет колонок, каждая не уже минимума. |
| clamp()? | Плавный размер между min и max. |
| dvh? | Высота с учётом панели адреса мобильного браузера. |
| hover/pointer? | Есть ли наведение и точный указатель. |
| Зачем sizes с fill? | Иначе браузер берёт 100vw и самый большой файл. |
| aspect-ratio? | Резерв места — нет CLS. |
| ResizeObserver у карты? | Карта сама не знает о смене размера контейнера. |
| Почему балл скачет? | Нагрузка CPU, сеть, кэш — берём медиану 3 запусков. |
| LCP / INP / CLS? | Крупнейший элемент / реакция на ввод / сдвиг макета. |
| Почему нет INP в Lighthouse? | Нет реальных действий пользователя, вместо него TBT. |
| Lab vs field? | Одна машина с эмуляцией vs реальные пользователи. |
