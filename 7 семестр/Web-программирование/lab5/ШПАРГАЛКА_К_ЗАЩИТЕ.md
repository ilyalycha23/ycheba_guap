## Частые вопросы — короткие ответы

| Вопрос | Ответ |
|--------|-------|
| Сервер vs база? | Процесс vs набор данных внутри него. |
| Кластер? | Все базы одного каталога данных под одним сервером. |
| Роль? | Учётная запись с правами. |
| Почему не postgres? | Суперпользователь — при взломе потеряем весь сервер. |
| База vs схема public? | Контейнер подключения vs пространство имён внутри. |
| Параметры psql? | `-h -p -U -d`. |
| `\conninfo`? | Текущие база, роль, хост, порт. |
| datasource / generator? | Куда подключаться / какой клиент генерировать. |
| Почему не NEXT_PUBLIC_? | Пароль базы уйдёт в браузер. |
| Percent-encoding? | `@ : / # %` ломают URL, `@` → `%40`. |
| Почему версии совпадают? | CLI генерирует клиент под свой движок. |
| validate / generate? | Проверка схемы / генерация типизированного клиента. |
| globalThis? | HMR не плодит пулы соединений. |
| migrate dev vs deploy? | Создать и применить в разработке vs применить готовые. |
| Почему без миграции? | Таблицы проектируем в ЛР6. |
| P1000 / P1001? | Неверная роль или пароль / сервер недоступен. |
