## Частые вопросы — короткие ответы

| Вопрос | Ответ |
|--------|-------|
| Путь запроса? | fetch → route.ts → сессия → Prisma → PostgreSQL → JSON. |
| HTTP-контракт? | Метод, путь, тело, ответ и статусы. |
| Почему проверять response.ok? | fetch не бросает ошибку на 4xx/5xx. |
| DTO? | Только нужные клиенту поля. |
| Зачем Number(Decimal)? | Иначе в JSON будет строка. |
| Где isTracked? | На сервере, клиенту не верим. |
| httpOnly cookie и fetch? | Браузер прикладывает сам, JS не читает. |
| loading vs empty? | Ответа нет vs ответ пустой. |
| AbortController? | Отмена устаревшего запроса. |
| Зачем loading в AuthProvider? | Не мигать гостевым видом. |
| Пессимистичное обновление? | UI меняется после ответа сервера. |
| unit / integration / E2E? | Функция / модули вместе / весь сценарий в браузере. |
| Почему E2E после build? | Проверяем реальную production-сборку. |
| Один worker? | Одна общая база. |
| Уникальный email? | Чтобы не получить 409. |
| waitForTimeout плохо? | Ждать надо состояние, а не время. |
