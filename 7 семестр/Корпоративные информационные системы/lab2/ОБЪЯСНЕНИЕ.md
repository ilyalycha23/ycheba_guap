# ЛР2 — IDEF0 «МебельПро»

**26 диаграмм** — полная декомпозиция всех веток.

## Как читать номера (это НЕ «сто двадцать один»)

По IDEF0 код узла — **иерархия**, цифры дописываются при декомпозиции:

- `A1` — 1-я работа на A0  
- `A12` — 2-я работа внутри A1  
- `A121` — 1-я работа внутри A12  → читается «A1-2-1», не «121»  
- `A211` — 1-я работа внутри A21 (ветка материалов)

Поле **«Номер»** внизу листа (1…26) — просто номер рисунка в отчёте.

## Дерево

A-0 → A0 → A1…A5  
A1 → A11…A14 (+ A12 → A121…A124)  
A2 → A21…A24 (каждый)  
A3 → A31…A34 (каждый)  
A4 → A41…A43 (каждый)  
A5 → A51…A54 (каждый)

Раскладки разные: лесенка, каскад, развилка, вертикаль, параллель — под процесс.
