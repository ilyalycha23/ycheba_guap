   - Partitioning
   - Linear Regression Learner
   - Regression Predictor

   - Scatter Plot

2. Соедини:
   CSV Reader → Color Manager → Partitioning
   Partitioning (верх/train) → Linear Regression Learner
   Partitioning (низ/test) → Regression Predictor (data)
   Linear Regression Learner (model) → Regression Predictor (model)
   Regression Predictor → Numeric Scorer
   Regression Predictor → Scatter Plot

3. Настройки:
   - **CSV Reader** → файл `Salary_Data.csv` выше
   - **Color Manager** → столбец `Salary`
   - **Partitioning** → Relative **20%**, sampling **Linear**
   - **Linear Regression Learner** → Target `Salary`, Include только `YearsExperience`
   - **Numeric Scorer** → Reference `Salary`, Predicted `Prediction (Salary)`
   - **Scatter Plot** → X `YearsExperience`, Y `Salary`
