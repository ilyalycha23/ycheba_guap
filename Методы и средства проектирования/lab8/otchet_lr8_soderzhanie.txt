Лабораторная работа №8 — содержание отчёта (методичка.pdf, гл. 8, п. 8.3, вариант 12)

1. Цель
   Курсоры в хранимых процедурах (ISO-синтаксис), сравнение типов курсоров (static / keyset / dynamic — по методичке, T-SQL; аналоги в PostgreSQL), изменение и удаление строк через UPDATE/DELETE … WHERE CURRENT OF.

2. Ход работы
   Подготовка: lab1, lab2. Выполнить lab8/01–07; при повторе — 09_drop_lr8_objects.sql.
   Текст по шагам — в лаба8_ход_работы.txt.

3. Таблица сводки
   Листинг 01_aux_stats_table.sql; назначение lr8_priem_stats.

4. Хранимые процедуры с курсором (ISO)
   02_proc_fill_stats_iso_cursor.sql — DECLARE, OPEN, FETCH, CLOSE, цикл.
   Скриншот Data Output после CALL lr8_fill_priem_stats().

5. WHERE CURRENT OF
   03 — UPDATE текущей строки курсора FOR UPDATE.
   04 — DELETE текущей строки.
   Скриншоты «до/после» из Data Output.

6. Типы курсоров (п. 8.2 методички)
   05_demo_cursor_types.sql: NO SCROLL, SCROLL, аналог STATIC (снимок TEMP), DYNAMIC (живая таблица), FOR UPDATE.
   Таблица соответствия T-SQL ↔ PostgreSQL из вывода скрипта 05.
   Пояснить: в PostgreSQL нет DECLARE … CURSOR STATIC|KEYSET|DYNAMIC.

7. Триггер с курсором
   06_trg_refresh_stats_cursor.sql — пересчёт lr8_priem_stats после DML на прием.
   Демонстрация из 07_demo_all.sql (INSERT → изменение сводки).

8. Вывод
   Когда курсор уместен; отличие ISO-синтаксиса от расширений T-SQL; роль WHERE CURRENT OF.

9. Приложения
   Файлы lab8/*.sql, lab1/01_schema.sql, lab2/01_insert_test_data.sql.
