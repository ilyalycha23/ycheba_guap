## Базовые понятия

**БСВ (базовая случайная величина)** — Z ~ U(0, 1), равномерное распределение на [0, 1].  
Генерируется через `random.random()`. Из неё получают другие распределения.

**Ряд распределения** (дискретная СВ): таблица P(X = k).

**Функция распределения:**
\[
F(x) = P(X \le x)
\]

**Числовые характеристики:**
- M(X) — математическое ожидание (среднее)
- D(X) — дисpерсия (разброс)
- σ(X) = √D(X) — среднее квадратическое отклонение

**Эмпирические оценки по выборке x₁, …, x_N:**
\[
M^* = \frac{1}{N}\sum_{i=1}^{N} x_i, \qquad
D^* = \frac{1}{N-1}\sum_{i=1}^{N}(x_i - M^*)^2
\]

## 1. Биномиальное распределение (вариант 9)

**Смысл:** n независимых испытаний, в каждом успех с вероятностью p. X — число успехов.

**Параметры:** n = 9, p = 0.45, q = 1 − p = 0.55

**Обозначение:** X ~ Bin(n, p)

### Формула вероятности

\[
P(X = k) = C_n^k \cdot p^k \cdot q^{n-k}, \quad k = 0, 1, \ldots, n
\]

\[
C_n^k = \frac{n!}{k!(n-k)!}
\]

### Характеристики

\[
M(X) = np = 9 \cdot 0.45 = 4.05
\]
\[
D(X) = npq = 9 \cdot 0.45 \cdot 0.55 = 2.2275
\]
\[
\sigma(X) = \sqrt{npq} \approx 1.49
\]

### Моделирование

**Метод суммирования Бернулли:** n раз генерируем Z ~ U(0,1); если Z < p — успех. X = число успехов.

### Что считалось в коде

- Ряд P(X = k) и F(x) для k = 0, …, 9
- P(X = 3), P(X ≥ 1), P(X ≤ 4), P(2 ≤ X ≤ 5)
- Выборка N = 500, сравнение теор. и эмп. вероятностей, M, D, σ
- Графики: ряд распределения, F(x), характеристики, гистограмма

## 2. Экспоненциальное распределение (формула 2.5)

**Параметр:** λ = 1

**Генерация из БСВ:**
\[
X = -\frac{\ln Z}{\lambda}
\]

**Плотность:**
\[
f(x) = \lambda e^{-\lambda x}, \quad x \ge 0
\]

**Характеристики:**
\[
M(X) = \frac{1}{\lambda}, \qquad D(X) = \frac{1}{\lambda^2}
\]

**Смысл:** время между событиями (ожидание, поломки и т.п.).

---

## 3. Равномерное распределение (формула 2.7)

**Параметры:** A = 0, B = 5 → X ~ U[0, 5]

**Генерация:**
\[
X = A + Z(B - A)
\]

**Плотность:**
\[
f(x) = \frac{1}{B - A}, \quad x \in [A, B]
\]

**Характеристики:**
\[
M(X) = \frac{A + B}{2}, \qquad D(X) = \frac{(B - A)^2}{12}
\]

---

## 4. Распределение Эрланга порядка K (формула 2.11)

**Параметры:** K = 3, λ = 1

**Генерация:**
\[
X = -\frac{1}{\lambda} \ln(Z_1 \cdot Z_2 \cdot \ldots \cdot Z_K)
\]

**Характеристики:**
\[
M(X) = \frac{K}{\lambda}, \qquad D(X) = \frac{K}{\lambda^2}
\]

**Смысл:** сумма K экспоненциальных СВ; время до K-го события. При K = 1 совпадает с экспоненциальным.

---

## 5. Нормальное распределение (формула 2.14, Бокс — Мюллер)

**Параметры:** m = 0, σ = 1 → N(0, 1)

**Генерация (из двух БСV Z₁, Z₂):**
\[
X = m + \sigma \sqrt{-2\ln Z_1} \cdot \sin(2\pi Z_2)
\]

**Плотность:**
\[
f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(x-m)^2}{2\sigma^2}\right)
\]

**Характеристики:**
\[
M(X) = m, \qquad D(X) = \sigma^2
\]

## Главная идея

Все непрерывные распределения получаются **преобразованием БСV** Z ~ U(0,1).  
Биномиальное — **дискретное**: сумма n испытаний Бернулли.

При большом N эмпирические значения приближаются к теоретическим (закон больших чисел). Небольшие расхождения при N = 500–2000 — нормальны.

## Краткая шпаргалка формул

**Биномиальное:** P(X=k) = C(n,k)p^k q^(n−k), M = np, D = npq

**Экспоненциальное:** X = −ln(Z)/λ, M = 1/λ, D = 1/λ²

**Равномерное:** X = A + Z(B−A), M = (A+B)/2, D = (B−A)²/12

**Эрланга:** X = −ln(∏Zᵢ)/λ, M = K/λ, D = K/λ²

**Нормальное:** Бокс — Мюллер, M = m, D = σ²
